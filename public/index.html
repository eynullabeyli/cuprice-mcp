Cuprice MCP Server provides public API tools for integrating Cuprice pricing widgets via Model Context Protocol. Tools: get-pricing (fetch plans and features by Share ID), get-embed-code (generate HTML/Next.js/React snippets), get-receipt (look up Stripe checkout purchases), get-css-classes (CSS selectors for widget customization). Hosted at mcp.cuprice.io/mcp. Documentation at docs.cuprice.io/mcp. Machine-readable at mcp.cuprice.io/llms.txt and mcp.cuprice.io/llms-full.txt.
