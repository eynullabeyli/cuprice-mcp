11 Tools Available

  • list-projects List all projects
  • get-project Get project details
  • get-shared-project Public data by Share ID
  • create-project Create a new project
  • update-project Update settings
  • add-feature Add to backlog
  • create-plan Create a plan
  • add-feature-to-plan Assign feature to plan
  • publish-project Publish & get Share ID
  • get-embed-code HTML/Next.js/React snippet
  • get-receipt Stripe purchase details

Cuprice MCP Server is a Model Context Protocol server that enables AI assistants to manage pricing projects. It supports creating projects, adding features, building pricing plans, publishing for embed, and retrieving Stripe payment receipts. The server is available as a hosted endpoint at mcp.cuprice.io/mcp or can be self-hosted. Full documentation is available at docs.cuprice.io/mcp. Machine-readable descriptions are at mcp.cuprice.io/llms.txt and mcp.cuprice.io/llms-full.txt.
