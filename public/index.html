Your pricing page, one prompt away

Connect Cursor, Claude or VS Code to the Cuprice MCP server. Your assistant reads the plans you published in Cuprice and writes the embed code for the framework you already use.

Server URL

https://mcp.cuprice.io/mcp

  • Streamable HTTP
  • No API key
  • 3 read-only tools
  • Open source, MIT

Connect your tool

Pick the tool you work in. The URL is the same everywhere; only where you paste it changes.

  1. Install it in one click. Cursor opens and asks you to confirm.

    Add to Cursor

  2. Or add it by hand: create .cursor/mcp.json in your project, or ~/.cursor/mcp.json to use it in every project.

  3. Open Cursor Settings and find cuprice in the MCP list. Its three tools show there once it connects.

  1. Run this in your project folder.

  2. Add --scope user before cuprice to use it in every project.

  3. Start Claude Code and type /mcp to check that cuprice is connected.

  1. Open Settings, then Connectors, and choose Add custom connector.

  2. Name it Cuprice and paste the server URL.

    https://mcp.cuprice.io/mcp

  3. No custom connectors on your account? Add it to claude_desktop_config.json through mcp-remote instead. It needs Node.js.

  1. Install it in one click. VS Code opens and asks you to confirm.

    Add to VS Code

  2. Or create .vscode/mcp.json in your project.

  3. Open Copilot Chat in agent mode. The Cuprice tools appear in the tools picker.

  1. Open ~/.codeium/windsurf/mcp_config.json and add the server.

  2. Refresh the MCP servers in Cascade. cuprice and its three tools appear in the list.

Every tool works from a Share ID. Publish a project in Cuprice and the share link ends with it: app.cuprice.io/share/your-share-id.

Then ask your assistant

Write it the way you would ask a colleague. Your assistant picks the tool and fills in the arguments.

  • Add my Cuprice pricing table to app/pricing/page.tsx. The Share ID is your-share-id.

    get-embed-code

  • List my Cuprice plans with their monthly prices and the features in each one. Share ID your-share-id.

    get-pricing

  • Style the Cuprice plan cards to match our site: 16px corners, our brand font, and our primary color on the buttons.

    get-css-classes

Three tools, all read-only

They read what your published page already shows. Creating and editing projects, plans and features is the REST API, with an API key.

get-pricing

Run it

Returns your published project: name, description, currency, annual discount, every plan with its features and limits, and the theme settings.

get-pricing inputs
InputTypeDescription
shareIdstring, requiredThe project's Share ID

Reads GET app.cuprice.io/api/share/{shareId}. An unknown Share ID comes back as a tool error with the API's message, so your assistant can tell you what went wrong.

get-embed-code

Run it

Writes the snippet that puts your pricing table or billing widget on a page, for the framework your project uses.

get-embed-code inputs
InputTypeDescription
shareIdstring, requiredThe project's Share ID
frameworkhtml nextjs react vueOptional, html by default
widgetpricing billingOptional, pricing by default

Run it yourself

The server is open source. Run it next to your own stack, or over stdio for a local tool.

Environment
VariableDefaultWhat it sets
PORT5000Port for the HTTP server
CUPRICE_BASEhttps://app.cuprice.ioWhere the Cuprice API and embed.js live

With Docker: docker compose up --build -d
